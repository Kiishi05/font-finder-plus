# Approved redesign prototypes

Standalone HTML prototypes the redesign is built from. Open any file in a browser.

- `index.html` Page tab, `details.html` font details, `image.html` Image tab,
  `system.html` System tab, `library.html` Library (Shelf), `settings.html` Settings.
  They link to each other like the real panel.
- `states.html` empty, loading and error screens (arrows to step through).
- `figma-plugin.html` the Figma plugin window (Paste, Fonts, Creating, Done).

Design rules agreed while reviewing them:
- Neutral greys, Geist, black primary buttons. Green only for "Free", amber for "Paid", red only for deleting and failing checks.
- White cards (18px corners), lighter grey boxes inside cards (--inset), 8px between cards, 18px card padding.
- Headings are plain text inside their card, never [BRACKETED] mono labels. A heading and its line of text sit 8px apart.
- Buttons 38px (small 34px, full width 44px). Fields 44px, filled, no outline; a dark ring only while typing.
- No outline strokes on fields, buttons or previews. Divider lines between rows are fine.
- Delete actions are red, icon included. Hugeicons only.
- Sub pages: back button in its own white square, then where you are. Settings only on the main top bar.
